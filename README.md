# Cadre Cinéma

Outil gratuit et open source dans le navigateur pour appliquer des ratios d'aspect cinématiques à une image.

**Démo** : [GitHub Pages](https://salimadour31-boop.github.io/cadre-cinema/) (activer dans Settings > Pages)

## Fonctionnalités

- Import d'image (glisser-déposer ou sélection)
- Presets : 2.39:1 Scope, 1.85:1 Flat, 16:9, 4:3, 2.0:1, personnalisé
- Modes : Letterbox (ajout de barres) ou Crop (recadrage centré)
- Couleur des barres personnalisable
- Aperçu en temps réel et export PNG
- Multilingue : Français, English, Tamazight (transcription latine)
- 100 % client-side : aucune donnée n'est envoyée au serveur

## Usage

1. Ouvrir `index.html` dans un navigateur ou utiliser la démo GitHub Pages.
2. Importer une image.
3. Choisir le ratio et le mode.
4. Ajuster si besoin et télécharger.
